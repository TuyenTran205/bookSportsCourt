🚀 KHỞI ĐỘNG NHANH
═══════════════════════════════════════════════════════════════════════════

  check-system.bat        → Kiểm tra toàn bộ hệ thống (DB, API, Frontend)
  start-dev.bat           → Khởi động đầy đủ (DB migration + seed + API + FE)
  stop-dev.bat            → Dừng tất cả server
  view-database.bat       → Mở Drizzle Studio xem database

═══════════════════════════════════════════════════════════════════════════

📊 DATABASE
═══════════════════════════════════════════════════════════════════════════

  pnpm --filter @bsc/api db:migrate       Chạy migrations
  pnpm --filter @bsc/api db:seed          Seed dữ liệu mẫu
  pnpm --filter @bsc/api db:studio        Mở Drizzle Studio (port 4983)
  pnpm --filter @bsc/api db:generate      Generate migration mới

═══════════════════════════════════════════════════════════════════════════

🌐 CHẠY SERVER
═══════════════════════════════════════════════════════════════════════════

  pnpm dev                                Chạy cả API + Frontend
  pnpm --filter @bsc/api dev              Chỉ API (port 3001)
  pnpm --filter @bsc/web dev              Chỉ Frontend (port 3000)

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

  Kiểm tra PostgreSQL:
    pg_isready -h localhost -p 5432

  Xem port đang dùng:
    netstat -ano | findstr ":3001"

  Kill process:
    taskkill /F /PID <PID>

  Reset database:
    psql ... -c "DROP DATABASE booksportscourt; CREATE DATABASE booksportscourt;"
    pnpm --filter @bsc/api db:migrate
    pnpm --filter @bsc/api db:seed
